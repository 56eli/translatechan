# Project State

Canonical project tracker. This file is the authoritative source for project state visible to agents and humans. The orchestrator branch never merges; this file does.

## 1. Owner Vision & Scope Boundaries

- **Product Vision:** Fake Chan Factory is a zero-backend static GitHub Pages reader for Classical Chinese Chan (Zen) literature (Tang/Song yulu, denglu, gongan). It presents English-first walnut-hall interface (gate: lintel + directory + beam hook "The old texts are real. The translators are not."), 5 public rooms only (Reader, Comparative Matrix, Lineage, Gong'an Index, Chan Lexicon), bilingual reading with source Chinese as largest text in Reader, multi-translator comparative alignment with explicit Robo/AI disclosure, lineage graph, gongan catalogue, lexicon. The corpus references CBETA/Taishō witnesses (T47, T48, T51, X-series) with honest source-review states (collated_to_claimed_witness, partial_or_failed_w1_collation, witness_unavailable). The project is playfully honest: most English renderings are 🤖 Robo — AI text in a famous translator's register, not citable as their work. A ✅ Edition-verified quotation badge means wording checked against recorded edition; rights review is separate.

- **Scope Boundaries (Non-Goals):**
  - Will NOT build Translation Studio, Arena AI Agents, header GitHub link — public scope stays exactly 5 rooms, smoke-guarded.
  - Will NOT generate source-looking Classical Chinese — corpus text comes only from pinned, digest-verified CBETA witnesses.
  - Will NOT approve rights — edition verification ≠ rights approval; rights_manifest.json sources await human/jurisdiction review.
  - Will NOT edit `.github/workflows/*` without explicit owner approval; OPERATIONS.md is sole register of owner-controlled CI changes.
  - Will NOT fetch/transcribe/evaluate OUT-OF-CBETA witnesses via agents — 31-document human-sourcing queue is human work only (Ruling 4, 2026-09-12).
  - Will NOT treat representation count (N/N cases) as completion — only explicit `completion_status: complete_selected_witness` + `collated_to_claimed_witness` + unit_targets met counts, per validator.
  - Will NOT edit `docs/` by hand — `docs/` is generated by `scripts/build_data_bundle.py` (mirror list); hand-editing is editing build artifact at wrong end.
  - Will NOT edit checker to make gate pass — when gate and prose disagree, prose is wrong; fix document, not validator/preservation/rules.
  - Will NOT re-point withdrawn false claims at unverified candidates — Ruling 3: false T1987 Zhaozhou claim withdrawn, not re-pointed.

## 2. Architectural Invariants

- **Pipeline order fixed:** `data/` → `scripts/validate_data.py` → `data/project_metrics.json` → `scripts/build_data_bundle.py` → root assets + byte-identical `/docs` mirror → GitHub Pages publishes `main/docs`.
- **Five quality gates pass before every push:** `python3 -m py_compile scripts/*.py` · `python3 scripts/validate_data.py` · `python3 scripts/build_data_bundle.py` · `python3 scripts/test_source_preservation.py` (allowlist, no unauthorized Chinese edits) · `python3 scripts/test_source_review_rules.py` (138+ checks, census pins, W1 evidence) · `node scripts/smoke_test.mjs` (dependency-free reader) · `git diff --exit-code -- app_data.js docs/app_data.js docs/data data/project_metrics.json`.
- **Gate execution:** unprivileged disposable clone, stdlib-only, read-only, exits 0 only when all checks pass. Minimum Python 3.11, tested 3.11/3.12/3.13, CI pins 3.12 in `.github/workflows/quality.yml`. Manifest checksums: every file in `data/corpus_manifest.json` must be verified by SHA-256; manifest nobody verifies proves nothing. Atomic ready marker checked last. See `GATE.md`.
- **Determinism:** `build_data_bundle.py` run twice must produce byte-identical `app_data.js` and `docs/app_data.js` (current hash `b68eb436ac8c847a0f92ec0dea8d0f74597aa8ee79778b5e5dfe8920bb9cdba7`, 8,143,493 bytes, 17 docs).
- **Source preservation:** `test_source_preservation.py` byte-compares `data/corpus/` against pinned base `3cc7a8e9681e` permitting only allowlisted exact JSON pointers (currently 218 permitted changes, 0 unauthorized).
- **Internal identifiers stay:** `translatechan_*` localStorage keys, `window.TranslateChan`, `TRANSLATECHAN_DATA`; public brand "Fake Chan Factory" and humor-forward tone stays.
- **Sessions append-only:** `sessions/` dated evidence never edited/deleted; new dated record supersedes old. `sessions/COLLATION_REGISTER_2026-09-09.json` historical, `sessions/COLLATION_REGISTER_2026-09-10_CORRECTION.json` correction, current authoritative `sessions/COLLATION_REGISTER_2026-09-22_P1_BIYANLU.json` (17 docs, 127 flagged, collated 13 partial 2 unavailable 2).

- **Completion rule:** `complete` ⇔ `complete_selected_witness` + `collated_to_claimed_witness` + unit_targets met (validator, `complete_document_keys()`, `per_text_metrics()`, Reader, shelf, smoke + runtime checks).
- **Witness rule:** Cite no work as text's witness unless ≥1 evaluated content field matches it — reference merely listed in `WITNESS` map is bibliographic pairing, not collation evidence. Current exception: none (previous dahui_hongzhi exception resolved).
