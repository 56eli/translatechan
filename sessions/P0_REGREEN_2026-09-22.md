## 4. HALTED — missing evidence citation, not a stale pin

or if the remaining failure is an evidence disagreement rather than a stale citation.

register. A read-only search of existing Markdown/text/JSON under `sessions/`, `docs/`
and `.orchestrator/` found no file citing that digest. Changing `CORRECTION_REPORT` to the
manifest-selected report therefore does not fix the assertion. The following experiment
sets that proposed pin only in process memory and runs the existing focused tests, which
mutate disposable sandbox copies, not the repository:
